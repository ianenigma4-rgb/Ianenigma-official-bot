║              SESSION / CREDENTIALS FOLDER                    ║
╚══════════════════════════════════════════════════════════════╝

This folder stores your WhatsApp session so the bot reconnects
automatically without needing to scan or pair every restart.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
OPTION A — Use the built-in pairing page (RECOMMENDED)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
The bot includes a self-hosted pairing page at:

    https://YOUR-APP-URL/pair

Steps:
1. Deploy the bot WITHOUT a SESSION_ID first
2. Open  https://YOUR-APP-URL/pair  in a browser
3. Enter your WhatsApp number (e.g. 256700123456)
4. A pairing code will appear — enter it in WhatsApp:
     Settings → Linked Devices → Link a Device
     → "Link with phone number instead"
5. Once paired, your SESSION_ID appears on the page automatically
6. Copy it and set SESSION_ID in your hosting env vars
7. Restart the bot — it will connect without pairing again

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
OPTION B — Drop creds.json here directly
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
If you already have a creds.json from a previous session:
1. Place it at  session/creds.json
2. Restart the bot — it connects immediately

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
OPTION C — Set SESSION_ID environment variable
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
If you already have a SESSION_ID string (from the pairing page):
1. Open .env and paste it:  SESSION_ID=IANENIGMA;;;xxxxxxx...
   OR set it in your hosting panel's environment variables tab
2. Restart the bot

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
NOTE: Option B (creds.json file) takes priority over SESSION_ID.
If creds.json already exists here, SESSION_ID will not overwrite it.
